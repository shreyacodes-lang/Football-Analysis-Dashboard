# Football Player Performance Analytics Dashboard

> **Synthetic Data Notice:** All player names, club names, and statistics in this
> project are artificially generated for demonstration purposes only. They do not
> represent real football players, clubs, or events.

---

## Features

| Feature | Detail |
|---|---|
| **Overview** | KPI cards (players, goals, assists, minutes, rating) + top-10 scorers + goals-by-position donut |
| **Player Analysis** | Side-by-side player comparison, Goals vs Assists scatter, Shots vs Goals scatter, searchable stats table, CSV download |
| **Team Analysis** | Team goals & assists, squad depth, average rating |
| **Position Analysis** | Box-plot distributions + radar archetype chart |
| **Sidebar Filters** | Season, Team, Position, Player — all cascading multiselects |
| **CSV Export** | Download filtered dataset from sidebar or Player Analysis page |
| **Theme** | Dark, football-inspired green-pitch UI built with custom CSS |

## Local Setup & Run

### 1. Clone or download the project

```bash
git clone <your-repo-url>
cd "Football Analysis Dashboard"
```

### 2. Create and activate a virtual environment (recommended)

```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Generate the synthetic dataset

> Skip this step if `football_players.csv` is already in the project folder.

```bash
python generate_data.py
```

Expected output:
```
[OK] Saved football_players.csv - 240 rows, 120 unique players.
    Seasons : ['2022-23', '2023-24']
    Teams   : ['Albion United', 'Eastgate Athletic', ...]
    Positions: ['Defender', 'Forward', 'Goalkeeper', 'Midfielder']
    Goals range : 0-35
    Rating range: 5.66-9.5
```

### 5. Run the dashboard

```bash
streamlit run app.py
```

The app will open automatically at **http://localhost:8501**.

## Deploy to Streamlit Community Cloud (free)

1. Push the project folder to a **public GitHub repository**.
2. Go to [share.streamlit.io](https://share.streamlit.io) and sign in with GitHub.
3. Click **New app** and select your repository.
4. Set **Main file path** to `app.py`.
5. Click **Deploy** — Streamlit Cloud installs dependencies from `requirements.txt` automatically.

> Make sure `football_players.csv` is committed to the repository so the deployed app can read it.

## KPI Calculations

All KPIs are computed at runtime from the filtered DataFrame — nothing is hardcoded.

| KPI | Formula |
|---|---|
| Total Players | `df["player_id"].nunique()` |
| Total Goals | `df["goals"].sum()` |
| Total Assists | `df["assists"].sum()` |
| Total Minutes Played | `df["minutes_played"].sum()` |
| Average Player Rating | `df["rating"].mean()` |

**Rating formula (computed during data generation):**
```
rating = clip(
    6.0 + goals * 0.15 + assists * 0.10
    + (pass_accuracy - 70) * 0.03
    + tackles * 0.02
    - yellow_cards * 0.05
    - red_cards * 0.20,
    min=5.0, max=9.5
)
```

This project uses a **fully synthetic dataset** generated by `generate_data.py` using
